# Changelog

## 0.1.2

- Play for a high score until no moves remain. Merging a 2048 tile leaves the round running.
- Save each mode only when its board changes.

## 0.1.1

- Rename the game to 2048 and add a scored, whole-board mode with swipes, tile spawning, and a 2048 goal.
- Keep the original ten challenges and their saves under Line puzzles.

## 0.1.0

- Add ten number-merging puzzles, line arrows, undo, and saved progress.
